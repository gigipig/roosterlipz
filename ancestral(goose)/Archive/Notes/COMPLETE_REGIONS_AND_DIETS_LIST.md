## 🗂️ Data Structure

Each of the 57 diet patterns includes:

### Core Information
- `id` - Unique identifier
- `name` - Display name
- `region` - Continental group
- `subregion` - Geographic subregion
- `culture` - Cultural/ethnic description
- `centroid` - Geographic center point (lat/lon)
- `bbox` - Bounding box coordinates

### Diet Information
- `diet_signature` - Comprehensive overview
- `staples` - Primary staple foods
- `common_foods` - Frequently consumed items
- `proteins` - Main protein sources
- `fats` - Primary fat sources
- `herbs_spices` - Common seasonings
- `cooking_methods` - Traditional preparation techniques
- `typical_dishes` - Representative meals
- `modern_substitutes` - Contemporary alternatives

### Nutritional Data
- `macros.carbs_pct` - Carbohydrate percentage
- `macros.protein_pct` - Protein percentage
- `macros.fat_pct` - Fat percentage
